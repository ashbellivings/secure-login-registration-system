Secure User Authentication System Using Full-Stack Web Technologies

A production-grade, full-stack web application implementing essential application security controls. Features salted Bcrypt password hashing (work factor 12), persistent server-side MongoDB sessions, session fixation defense, backend access control, rate limiting, and audit-ready security verification.

Create Your Account Security Controls Guide Run 17 Automated Tests

Password Hashing

Passwords are never stored in plaintext. Passwords are transformed on the backend using Bcrypt with a work factor of 12. Password hashes are never returned across API boundaries.

Server-Side Sessions

Utilizes Express-Session and connect-mongo with HttpOnly, SameSite cookies. Tokens are regenerated upon login to prevent session fixation, and destroyed on logout.

Server Access Control

Protected routes rely exclusively on verified server-side session state. Browser-supplied user IDs are never trusted, completely preventing IDOR privilege escalation attacks.
